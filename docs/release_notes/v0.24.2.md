# 0.24.2 Release Notes

Released 2026-11-06. Changes since tag `0.24.1`.

## Security and dependency updates

This release refreshes runtime, application, frontend, and CI dependencies to
their latest compatible stable versions checked on the release date.

| Component | Version |
| --- | --- |
| .NET SDK | 10.0.403 |
| ASP.NET runtime and Microsoft .NET/EF Core servicing packages | 10.0.14 |
| HtmlSanitizer | 10.0.1120 |
| AngleSharp / AngleSharp.Css | 1.9.1 / 1.3.2 |
| Markdig | 1.6.0 |
| Azure.Core | 1.64.0 |
| Microsoft Identity Client (MSAL), Broker, and Extensions.Msal | 4.92.0 |
| OpenTelemetry HTTP instrumentation | 1.20.2 |
| TinyMCE | 8.10.1 |
| Sekura design assets | 3.2.2 |
| Playwright | 1.65.0 |
| GitHub setup-dotnet action | 6.1.0 |
| Trivy | 0.76.2 |

The TinyMCE sanitizer module is rebuilt with DOMPurify 3.4.17, retaining the
existing sanitizer hardening. Frontend source hashes, generated asset integrity
metadata, and dependency lockfiles are refreshed. Other dependencies already on
their current stable versions are retained.

Microsoft.Build.Framework and Microsoft.NET.StringTools remain pinned to 18.9.6
for .NET 10 compatibility. Newer versions were checked: their .NET 11 runtime
assemblies cannot run on this application's .NET 10 target, despite package
reference metadata that may permit restore.

## Reliable locked builds

Scheduled GitHub builds began failing with `NU1004` when SDK roll-forward selected
10.0.403 while the checked-in lockfiles still described the previous SDK's
implicit dependencies. The SDK is now pinned exactly with `rollForward: disable`;
the Docker build uses the same SDK, and lockfiles are regenerated together with
the SDK upgrade. GitHub Actions remain pinned to commit SHAs, and the Trivy
download is verified against its release checksum.

## Upgrade

Install .NET SDK **10.0.403** for local builds, then restore using the checked-in
lockfiles. Framework-dependent deployments require the .NET/ASP.NET **10.0.14**
runtime. Rebuild container deployments with `docker build --pull` to obtain the
updated runtime and base-image packages.

This release has no application database schema changes or new configuration
requirements. Existing journal records, files, favorites, and encryption keys
continue to use the same storage format.

## Validation

All **189 automated tests** pass, including the added sanitizer regressions.
Bundled frontend assets pass version and integrity verification. NuGet auditing
across all three projects and npm auditing report no known vulnerabilities;
the frontend maintenance packages have no outstanding stable updates.

Browser checks against the release container pass for sign-in, project creation,
rich-text entries, project locking, multiple-file uploads and exact downloads,
favorites, Quick read, mobile navigation, and light/dark layouts. The browser
sanitizer regression tests also pass with the rebuilt editor.

The built 0.24.2 container uses Alpine 3.24.4. Its Trivy scan reports no known
vulnerabilities across all severities, including findings without available
fixes. These results reflect the advisory databases available at release time.
