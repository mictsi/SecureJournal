# 0.21.0 Release Notes

Released 2026-10-25. Changes since tag `0.20.0`.

## Usability

- Role-aware navigation sends auditors to audit work and keeps project context when creating or opening journal entries.
- Journal pages offer clearer filters, useful empty states, explicit save feedback, and readable record cards on phones.
- Project creation ends with an access review, preserves drafts while moving between steps, and provides recovery when a group operation fails after the project is created.
- Export creation separates configuration, review, and download, with date validation and clear plaintext-export guidance.
- Administrative searches preserve selected records and unsaved edits. Destructive actions identify their target before confirmation.
- Mobile navigation supports Escape and dismissal, and stays open when an unsaved-change prompt cancels navigation.

## Security and maintenance

- Sanitized Markdown output as well as editor HTML; rebuilt TinyMCE 8.10.0 with DOMPurify 3.4.17 and removed its unused legacy codesample plugin.
- Restricted authentication return URLs to local destinations and corrected antiforgery middleware ordering.
- Made stored local memberships authoritative and invalidated revoked, expired, or replaced sessions in existing application circuits.
- Enabled failed-login lockout and revoked affected sessions after password resets, account disabling, or deletion.
- Restricted forwarded headers to trusted proxies and removed raw tokens, bootstrap passwords, and new journal subjects from sensitive diagnostic/audit paths.
- Updated direct and transitive dependencies, Sekura assets, .NET SDK/runtime, Docker bases, and GitHub Actions. Two build libraries remain on 18.9.6, the latest .NET 10-compatible versions.
- Added central package versions, checked-in lockfiles, frontend integrity checks, Dependabot, and CI vulnerability gates for dependencies and the final container image.

## Upgrade notes

- Install .NET SDK 10.0.402 or a later servicing patch in that feature band, as selected by `global.json`.
- Docker Compose requires `SECUREJOURNAL_JOURNAL_ENCRYPTION_KEY` and `SECUREJOURNAL_BOOTSTRAP_ADMIN_PASSWORD`. Preserve the existing encryption key when upgrading so stored journal entries remain readable.
- Configure the actual reverse-proxy IPs or CIDRs under `ForwardedHeaders:KnownProxies` or `ForwardedHeaders:KnownNetworks`. Verify sign-in callbacks and HTTPS redirects for the deployment.
- The container uses .NET 10.0.13 on Alpine 3.24 with ICU and timezone data, running as UID/GID 10001. Active configuration and private keys are excluded from image builds; supply them through deployment configuration.
- Historical audit records remain unchanged. New journal-creation audit events no longer duplicate the journal subject.
- SQL Server and PostgreSQL validation covers offline provider loading and SQL/schema generation. Live connections and authentication require environment-specific validation.

See [building](../BUILDING.md) and [deployment configuration](../LOCAL_DEPLOYMENT_AND_CONFIGURATION.md) for commands and settings.

## Validation

- 118 automated tests passed.
- Browser checks passed for administrator, project-user, and auditor workflows, draft protection, export download, wizard failure recovery, and 320px/390px phone layouts.
- Browser sanitizer regressions reproduced the original vulnerable behavior and verified the patched editor removes it.
- NuGet, npm, and the final production-container scan reported zero known vulnerabilities on 2026-10-25, with all severities and unfixed findings included.
- The production container passed startup, SQLite initialization, health, and sign-in checks as a non-root user with a read-only filesystem.
