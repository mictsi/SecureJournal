# 0.21.1 Release Notes

Released 2026-10-25. Changes since tag `0.21.0`.

## Fix

Journal View, Delete, and Restore buttons retain their intrinsic width in desktop
tables, preventing their labels from wrapping letter by letter. On phones, the
action area can still wrap whole buttons without squeezing their text.

This patch retains the usability, security, and dependency changes in
[0.21.0](v0.21.0.md). Its [upgrade requirements](v0.21.0.md#upgrade-notes) continue
to apply. There are no database or configuration changes in this patch.
