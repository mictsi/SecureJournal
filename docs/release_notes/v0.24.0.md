# 0.24.0 Release Notes

Released 2026-10-25. Changes since tag `0.23.0`.

## Quick read

Quick read is now a two-column reading view. A paged entry list appears on the left; selecting an entry displays its full description, notes, deletion context, and downloadable files on the right. The reader initially asks for a selection. Switching entries resets its scroll position. Search, sorting, and page changes clear selections outside the visible page, while browser history and return links retain valid selections.

On smaller screens the list opens a dedicated detail view; Back to entries restores focus to the selected row. The compact list and inline Show entry behavior are retained.

## Project favorites

Favorite buttons on project cards and headers save preferences to the signed-in account. Show favorites appears beside Show my projects. Favorites can be searched and paged, and the filter survives opening a project or creating an entry. Removing the last item on a page adjusts paging and returns keyboard focus to the results.

Favorites persist across logins and application restarts. They never grant project access: every read/write resolves the current user and checks current role, session, and project access. Preferences remain stored while access is temporarily unavailable, but are hidden until access returns. Account and physical project deletion remove the associated preferences. Favorites are not shared between users.

## Upgrade and validation

Startup adds the `project_favorites` table, composite key, foreign keys, and project index to SQLite, PostgreSQL, or SQL Server. Existing records and files are unchanged. Back up the databases before upgrading; the application database account needs permission for this additive schema change. No new packages or configuration are required. Existing file-size limits remain unchanged.

All 185 automated tests pass, including favorites isolation, persistence, idempotency, access/session revocation, cascades, and upgrades from existing databases. Browser checks cover the two-pane reader, selection/history/paging, file downloads, scroll reset, favorites workflows, keyboard focus, mobile layouts, themes, and 200% text. Live PostgreSQL 18.6 and SQL Server 2022 checks also cover repeatable schema creation, separate user preferences, concurrent idempotent inserts, deletion, and foreign-key enforcement.
